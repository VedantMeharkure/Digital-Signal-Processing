# Digital-Signal-Processing

A collection of Digital Image Processing (DIP) mini-projects and exercises implemented in Python (OpenCV, NumPy, Matplotlib) and MATLAB.

## 📁 Repository Structure

| Folder | Description |
|---|---|
| `DIP_MATLAB-ONRAMP` | Exercises and notes from the MATLAB Onramp course, covering the basics of MATLAB syntax, matrices, and plotting. |
| `DIP_RGB_TO_GREY` | Converts a color (RGB) image to grayscale using OpenCV. |
| `DIP_RGB_TO_LAYERS.py` | Splits a color image into its individual Red, Green, and Blue channel layers and visualizes them using Matplotlib. |
| `DIP_Tambola_Tickets` | A script/project related to generating or processing Tambola (Housie) tickets. |

## 🛠️ Requirements

- Python 3.x
- OpenCV (`opencv-python`)
- NumPy
- Matplotlib
- MATLAB (for the MATLAB Onramp exercises)

## 📌 Notes

- Each project folder is self-contained — place any required input images inside the respective folder before running its script.
- Output images/plots are generated using OpenCV and Matplotlib and displayed directly, or saved locally depending on the script.
